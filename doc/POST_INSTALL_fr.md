Carbure est installé à l'adresse <https://__DOMAIN__/portal/>.

1. Connectez-vous avec l'identifiant **__ADMIN__** et le mot de passe choisi à l'installation.
2. Dans **Comptes**, ajoutez votre banque (bouton **+**), puis choisissez les comptes à suivre.
3. Dans **Mon profil → Double authentification**, protégez votre compte.
4. Sur votre téléphone, installez l'application ([iPhone](https://apps.apple.com/fr/app/carbure/id6824057363),
   [Android](https://play.google.com/store/apps/details?id=org.carbure.app)), puis scannez le
   QR code de **Mon profil → Mes appareils**.

Tous les comptes sont synchronisés chaque jour à __SYNC_HOUR__ h __SYNC_MINUTE__. Les
notifications push s'activent dans **Administration → Push mobile**.
